# Brand Style Guide — kodevelop.be

## 1. Brand identity

- **Brand name:** kodevelop.be
- **Tagline:** software & architecture
- **Visual style:** Modern · technical · minimal · reliable · intelligent

The logo mark combines four ideas:

- **Umbrella:** protection, support, and reliability
- **Leaf/plant:** growth, development, and structure
- **Central stem:** architecture and a clear technical foundation
- **Circle at the bottom:** a subtle technical/abstract element that makes the mark recognizable

## 2. Logo

### Primary version

The primary logo consists of:

- The dark navy logo mark
- The bold kodevelop.be wordmark
- The lighter software & architecture tagline

Preserve the proportions between all three elements.

### Clear space

Leave clear space around the logo at least equal to the diameter of the small circle beneath the logo mark. Do not place text, images, or other graphic elements within this area.

### Do not

- Stretch or distort the logo.
- Add a drop shadow.
- Use gradients.
- Apply other colors unless they are part of an approved brand variation.
- Separate the logo mark and wordmark arbitrarily.
- Add an outline around the logo.

## 3. Brand colors

The primary color in the generated logo is a vivid, very dark blue.

### Primary navy

- **HEX:** `#002E6F`
- **RGB:** `0 / 46 / 111`
- **CMYK:** `100 / 59 / 0 / 56` (approximate print value)

This is the color I would establish as the official Kodevelop blue. It is dark enough to feel professional and technical, while having more character than classic black.

### Supporting colors

Keep the palette intentionally limited:

| Color | HEX | Use |
| --- | --- | --- |
| Kodevelop Navy | `#002E6F` | Logo, headings, buttons, accents |
| Deep Navy | `#001F4D` | Dark backgrounds, footer |
| Off White | `#F7F9FC` | Backgrounds |
| White | `#FFFFFF` | Logo on dark backgrounds |
| Cool Grey | `#64748B` | Secondary text |
| Light Grey | `#E8EDF3` | Lines, cards, backgrounds |

`#002E6F` should remain the dominant brand color.

## 4. Typography

I would use Poppins for the brand. Its geometric, rounded shapes complement the current logo and give Kodevelop a contemporary, technology-focused look.

- **Primary typeface:** Poppins
- **Availability:** Google Fonts

### Weights

| Weight | Use |
| --- | --- |
| Poppins ExtraBold / 800 | kodevelop.be, large titles, key statements |
| Poppins SemiBold / 600 | Taglines, subheadings, buttons |
| Poppins Regular / 400 | Body text, website content, documentation |
| Poppins Light / 300 | The software & architecture tagline; optionally, large secondary text |

## 5. Typographic hierarchy

Suggested website sizes:

| Element | Typeface weight | Size |
| --- | --- | --- |
| H1 | Poppins 700/800 | 48–56 px |
| H2 | Poppins 600 | 32–40 px |
| H3 | Poppins 600 | 22–28 px |
| Body | Poppins 400 | 16–18 px; line height approximately 1.6 |
| Tagline | Poppins 300 | 14–18 px, with generous letter spacing |

For the logo, I would make the wordmark slightly heavier than standard Poppins ExtraBold, or consider a customized/outlined version. This helps kodevelop.be remain bold and legible at small sizes.

## 6. Logo color variants

### Positive version — on white

Use the logo mark, kodevelop.be wordmark, and software & architecture tagline in `#002E6F` on white. This is the primary version.

### Reversed version — on dark

Use the logo in `#FFFFFF` on a dark navy background. This version is suitable for:

- Website footers
- Dark presentation slides
- Social media
- Dark banners

## 7. Visual style

The rest of the brand should deliberately align with the logo.

### Do

- Use plenty of whitespace.
- Use straight, clear grids.
- Use geometric shapes.
- Use subtle rounded corners.
- Use dark navy as an accent.
- Use technical diagrams.
- Use minimalist icons.
- Keep layouts calm and uncluttered.

### Avoid

- Using too many colors.
- Using gradients.
- Using loud technology illustrations.
- Using stock photos with exaggerated “IT” imagery.
- Using too many rounded elements.
- Using conventional corporate blue-and-gray styling.

The combination of dark navy, white, Poppins, and geometric lines gives Kodevelop a distinctive identity without making it look like a typical “software developer” brand.

## 8. Example color balance

Suggested proportions:

- **70%** white/off-white
- **20%** dark navy
- **10%** gray and supporting shades

This keeps the brand light and modern.

## 9. Social and web use

For a favicon or small profile image, use only the logo mark rather than the full logo:

**Umbrella/leaf + stem + circle**

The mark is distinctive enough to work as a standalone identifier.

For larger applications, use the full logo:

- **kodevelop.be**
- *software & architecture*
